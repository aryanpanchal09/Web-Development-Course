 🛠️ Node.js Web Server Setup – Intro Lesson Notes

 🗂️ Project Initialization
- Started in Visual Studio Code.
- Empty project folder containing:
  - .gitignore file (optional; for version control).

 📁 Creating Entry File
- New file named server.js or app.js.
- Acts as the entry point for the Node.js application.

 📦 Importing Core Modules
- Used Node.js http module.
- Imported via:
  js
  const http = require('http');
  

 🧠 Defining Request Listener
- Function handles incoming requests and responses.
- Signature looks like:
  js
  const requestListener = (req, res) => {
    // logic here
  };
  

 🖧 Creating and Starting the Server
- Created using:
  js
  const server = http.createServer(requestListener);
  
- Server listens on a port (commonly 3000):
  js
  server.listen(3000);
  

 🌐 Server Behavior
- Keeps listening continuously for requests.
- Accessing localhost:3000 in a browser triggers requestListener.

 📌 Key Takeaway
- This setup is the foundation of a Node.js web server.
- Future lessons will:
  - Dive into handling specific request types.
  - Explore crafting responses.
